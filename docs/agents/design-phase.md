# Adding content in the Design phase

During the Design phase the site holds only placeholder content. A skill that adds an item to `content/` sends you here when a neighbour of the item is a placeholder.

Ask the Maintainer, in the same round as the skill's other questions, whether the item is a **placeholder** or a **real** item to add before Design approval all the same.

A placeholder:

- opens its front matter with the comment its neighbours open with (`# Design-phase placeholder, not a real Publication. Replace in the Content phase.`, and `not a real talk`, `not real News`, `not a real person` for the other types);
- has made-up details, `https://example.org/` links, and names only placeholder people (`member-name-*`, `alumnus-name-*`, and `Collaborator Name One` and so on for a Collaborator): the PI's file is a real person's, so a placeholder leaves it out. A real link or name the Maintainer gives for a placeholder is left out, and the Maintainer told;
- as a Publication, has no real DOI or arXiv page: give `add-publication` a BibTeX entry with the made-up details.

Done when: the Maintainer has said placeholder or real, and a placeholder meets the three points above.
